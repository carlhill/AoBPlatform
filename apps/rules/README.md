# Rules & Conformance service (M4)

The s 65C rules engine (rules C1–C14 per REQ-65C-01), versioned rule-set and
Basic Service Description mapping content (REQ-REG-03, REQ-65C-02), conformance
statement generation (REQ-65C-03), and the public compliance tester front door
(REQ-TEST-*). Holds **zero PII** — ADR A-07.

> ⚠ **Human-authored zone.** Per CLAUDE.md §7 and the build plan, the rule
> implementations here are written and reviewed by humans. Claude/agents may
> write tests, review, and refactor — not author the rule set wholesale.
> Never invent regulatory facts: section numbers, dates, data elements and
> thresholds come from `.claude/docs/aob-requirements.md` (v0.4).

Language guardrail (rule 12): nothing generated by this service ever says
"certified", "approved", "accredited" or "government-approved". Permitted:
"checked against the s 65C data set", "self-assessment".
